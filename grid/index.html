PRÀCTICA 02

Tauler de notícies amb CSS Grid

Grid reparteix una pàgina en files i columnes. Modifica les àrees per veure com es reordena el tauler.

DESTACADA

Un disseny, moltes possibilitats

La notícia principal ocupa més espai.

TECNOLOGIA

Aprendre fent

Experimenta amb `fr` i `gap`.

DISSENY

Menys és més

Les àrees tenen noms descriptius.

AGENDA

Divendres: mostra de projectes

Canvia la seua posició.

Lectura del tauler

grid-template-columns: repeat(3, 1fr) crea tres columnes iguals.

grid-template-areas dibuixa la distribució amb noms. Una paraula repetida ocupa més d'una cel·la.

En pantalles menudes, una media query substitueix el dibuix per una única columna.
