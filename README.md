# CSS — exemples vius de Flexbox, Grid i Responsive

Material de suport per a l'explicació a classe. No són exercicis: cada pàgina mostra el resultat real de les propietats CSS perquè professorat i alumnat puguen veure el canvi, consultar el codi i modificar-lo en directe. No cal instal·lar res: obriu qualsevol `index.html` amb el navegador (idealment amb **Live Server** a VS Code).

## Estructura

| Carpeta       | Contingut                                    | Objectiu principal                                |
|---------------|----------------------------------------------|---------------------------------------------------|
| `flexbox/`    | Comparativa estàtica/flex i components reals | Eixos, alineació, `flex-wrap` i `flex`            |
| `grid/`       | Comparativa normal/grid i tauler real        | Columnes, fraccions, àrees i `minmax()`           |
| `responsive/` | Una pàgina que canvia en redimensionar       | *Mobile first*, media queries i graella adaptable |

En cada carpeta hi ha:

- `index.html`: els exemples visuals i una explicació breu de cada transformació.
- `styles.css`: el CSS real, amb comentaris que podeu consultar a l'editor.
- `APUNTS.md`: resum de les propietats que apareixen a la demostració.

## Proposta de sessió (120 min)

1. **10 min** — Presentar l'inspector del navegador i la regla CSS.
2. **35 min** — `flexbox`: comparar el flux normal amb la fila flexible.
3. **35 min** — `grid`: comparar el flux normal amb el tauler de columnes.
4. **30 min** — `responsive`: redimensionar la finestra i observar els punts de ruptura.
5. **10 min** — Torn obert per modificar una propietat i comentar-ne l'efecte.
